# Assets do repositório

Esta pasta existe para concentrar os arquivos visuais usados no `README` e em futuras documentações do projeto.

## Estrutura sugerida

```text
docs/
├── README.md
└── assets/
    ├── screenshot-home.png
    ├── create-map.gif
    ├── import-markdown.gif
    └── export-map.gif
```

## Convenção recomendada

- `screenshot-home.png`: visão geral da tela principal
- `create-map.gif`: criação e conexão de nós
- `import-markdown.gif`: fluxo de importação de Markdown
- `export-map.gif`: fluxo de exportação

## Dicas rápidas

- prefira capturas em `PNG`
- use GIFs curtos, de 5 a 10 segundos
- mantenha largura consistente entre os assets
- evite capturas com menus temporários abertos, a menos que estejam demonstrando uma feature
